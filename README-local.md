# README-local

This is a long-living fork of [T3 Code](https://github.com/t3dotgg/t3code), currently branched from `v0.0.42`.

- Local changes on top of upstream live here, each self-contained in its own well-documented commit.
- Rebase onto newer upstream releases as they come out, but only when the user explicitly requests it — no agent should initiate a rebase on its own.
- When rebasing, keep local commits separable so they can be reapplied cleanly on the next rebase.
